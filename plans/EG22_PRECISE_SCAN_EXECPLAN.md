# Scan the EG22 and refine its measured workpiece frame

Maintain this living ExecPlan under `PLANS.md` and the repository's `AGENTS.md`. Paths are relative to the repository root.


## Purpose / Big Picture

In Measuring / Precise, Generate Path and Dry Run continue to prepare and play an animation. RSI Sampling translates that saved motion into the controller job. Scan measures the mounted EG22, and Resume continues the same interrupted run. After normal completion, RoboCrap fits three measured faces and archives the observations. Scan complete displays the displacement from the previous placement. Reassign saves the measurements as authoritative and places the gauge and stand. Cancel keeps the previous placement. Reopening Calibration or Precise restores the accepted frame. The gauge follows its origin and orientation. Its stand follows only its origin.

A Refine Job stores CAD faces and grid cells in the gauge's native frame {Wc}. A Scan Path belongs to one job revision, mounting and probe orientation. A sampled job pairs controller commands with numbered search streams. One physical attempt supplies the actual measurements for the fitted frame {Wr} in robot base coordinates {B}. Frame {F} is the robot flange.

## Surprises & Discoveries

`docs/hardware_context/HARDWARE_SETUP.md` and `docs/code_context/ARCHITECTURE.md` identify KUKA `$OUT[2]` as wired to PLC input X1.1 and unassigned in the documented installation. RobotIo's X1 mask already includes bit 1; the PLC transmits the whole byte on change and in snapshots. `PlcMessageManager::ioState()` exposes all eight bits as `x1`. The historical `plc.csv` header omits X1.1. `PlcDevice::nextProgramState()` derives Finished when CELL requests another program after execution. A KRL error return can produce the same transition.

Before M4, `SceneCalibration::reloadEndGauge()` removed the old gauge before checking insertion. A failed insertion could therefore remove good geometry. Before M3, Geometry used one radius for plane offsets and the bottom of the physical ball. Those radii coincide for the supplied rough file but can differ after calibration.

### M3. Fit the measured planes once and record their residuals

At sampling snapshot the applied primary source, ball centre in {F}, vertical/horizontal contact distances, reference sphere radius and actual probe configuration. `docs/calibration/ROBOT_PROBE_SPHERE_CALIBRATION_METHOD_RU.md`, equation (5.3.3), gives the effective radius in mm as the applied contact distance for the orientation class minus the reference sphere's nominal radius (12.5 mm for SPH25). G1 uses the vertical distance and G2 the horizontal distance. Verify the sampled probe mounting/orientation agrees with that class. Only one group is used for all three scan faces. Reject missing, manual/stale or inconsistent primary values, settings errors, a nonpositive radius, mixed groups, or a TCP inconsistent with the applied ball centre. A changed primary invalidates an old sample even if only the contact distances changed. Reassign remains the only way to promote the last calibration result. A newer unapplied result alone does not invalidate an older valid primary.

For each actual detection, evaluate `Kr10Kinematics(motion.robot().model).solveFK(joints).back()` on its finite, in-range joint angles. Multiply that flange-to-base transform by the sampled flange-to-TCP transform. Its translation is the observed ball centre in {B}, in mm.

Match the finite TCP pose to its indexed Approach row before assigning the centre to that face and cell. In {B}, project the displacement from the planned search start to the detected centre onto the row’s unit inward search direction. Check the signed distance against zero through the row’s permitted travel (gap plus overtravel), the perpendicular distance from the search line in mm, and the smallest rotation angle in degrees between detected and planned TCP orientations. Use documented physical bounds for axial uncertainty, lateral error and angular error applicable to the sampled robot, probe mounting, TCP calibration, feed and detection timing. Record the bounds and their measurement or commissioning basis with the job. Axial uncertainty applies only to the measured pose. Commanded travel keeps its original limit. Without justified bounds, physical Scan stays unavailable. Record each available deviation by touch number. An unevaluable or out-of-bounds pose fails the run before fitting or saving precise observations. The nominal grid point, planned endpoint and accumulated RSI increments are never substituted for missing measurements.

In `src/geometry/include/geometry/endgaugefit.h` give `EndGaugeObservations` two explicit positive finite scalar inputs, `compensationRadiusMm` and `physicalBallRadiusMm`. In `src/geometry/endgaugefit.cpp`, change only the radius operands: subtract the compensation radius from each oriented plane offset in `fit()`; subtract the physical radius from the observed centre height in `checkContacts()` when testing the clamp. For legacy rough JSON, map the existing `ballRadiusMm` to both fields. For precise input, use the selected group's effective radius for compensation and half the sampled ruby ball diameter for clearance (nominally 1.5 mm). Supply raw centres to the fitter. Keep its plane SVD, signed normals, angle/rank checks, corner intersection, orthonormal axes, projection, edge limits and clamp allowance. Motion and overtravel checks retain the physical radius. For example, a hypothetical centre at local Z=−25.6 mm with nominal radius 1.5 mm reaches −27.1 mm and violates the −27 mm clamp boundary even if its effective radius is only 1.35 mm.

Calculate residuals **before shifting the plane**. `Plane::fromPoints()` in `src/geometry/plane.cpp` already returns unit-normal coefficients. For one face let a, b and c be its unit normal components in {B} and d its constant term in mm, all oriented outward using the fitter's existing sign. The signed orthogonal residual of a measured centre with coordinates X, Y, Z in base mm is $r(X,Y,Z)=aX+bY+cZ+d$. In the existing face loop evaluate this once for every centre. Carry the signed values, in input order for each face, in `EndGaugeFit` alongside its existing placement/diagnostic result. This small result addition avoids refitting planes or parsing diagnostic text. Retain residuals for planes already fitted if a later check fails. For an unfittable plane report the existing reason and leave its residual statistics unavailable.

Join each residual back to the touch number via the same face grouping. In the scan session's measured-centre rows (`observations.csv`), write `touch`, face/cell identity, base X/Y/Z in mm and `plane_residual_mm`. For each fitted face record sample count, root mean square (square root of the sum of squared residuals divided by that count), and maximum absolute residual, both in mm. Preserve available diagnostics in the failure attachment as well; `recordFor()` emits its `result` member only on success. The summaries describe scatter about each independently fitted ball-centre plane. There is no new residual rejection threshold.

**Acceptance.** Each acquired row can be traced from recorded joints to one base-frame centre and one signed plane residual.
