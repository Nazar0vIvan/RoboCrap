# Калибровка центра шарика WP-500 по эталонной сфере: установка и метод

## 1. Назначение документа и состояние

Документ проецирует теорию из `docs/calibration/ROBOT_PROBE_SPHERE_CALIBRATION_THEORY_RU.md` (далее **«теория»**) на установку проекта: робот KUKA KR 10 R1420 с контроллером KR C4, щуп WP-500, эталонная сфера Ø25 мм, ПЛК Delta, интерфейс RSI. Обозначения, термины и номера формул — из теории; новые введены там, где используются. Анализ литературы — `docs/calibration/ROBOT_PROBE_SPHERE_CALIBRATION_LITERATURE_RU.md` (далее **«анализ литературы»**); математика для ММК — `docs/calibration/ROBOT_PROBE_SPHERE_CALIBRATION_MODELS_RU.md` (далее **«модели»**), номера её формул начинаются с буквы m.

Задача: найти положение центра рубинового шарика WP-500 относительно фланца робота, чтобы затем измерять поверхности деталей этим щупом. Сейчас известно только приближение TOOL_DATA[5]: X −0,048, Y −0,097, Z 127 мм.

Состояние: метод определён. Документ содержит данные установки (разделы 2–4), математическую модель калибровки и проверки (раздел 5), процедуру калибровки (раздел 6) и процедуру проверки (раздел 7); КТК — по теории, раздел 4. Расчёт движения, задание для контроллера, выполнение касаний и их регистрация (шаги К2–К5, В1, В2) реализованы; два полных сеанса по 158 касаний выполнены 2026-11-14 и 2026-11-17 (`plans/PROBE_SPHERE_RSI_CALIBRATION_EXECPLAN.md`). Оценивание параметров по базовой модели (5.2.1), $s_{\mathrm{rep}}$, центр сферы по проверочным касаниям, невязки и $\chi_{95}$ (шаги К6, В3, В4) реализованы в приложении: результат показывается после выполнения программы и записывается в папку записей сеанса, но не применяется как TCP щупа (`plans/PROBE_SPHERE_CALIBRATION_RUN_EXECPLAN.md`). На шаге К7 средние невязки по кольцам наклона и поворотам и их границы только выводятся; расширение модели не реализовано. Классификация эффектов факторов по признакам теории (раздел 5.4) не выполнена.

### 2.2. Системы координат на контроллере

- {B} совпадает с WORLD KUKA: программа задаёт `$BASE = $NULLFRAME`, `$ROBROOT` в машинных данных нулевой.
- {F} — система FLANGE KUKA; в проекте — последнее преобразование `Kr10Kinematics::solveFK`.
- {P} — TOOL_DATA[5] с $A = B = C = 0$.

KUKA задаёт позу координатами X, Y, Z, мм, и углами Эйлера Z-Y-X $A$, $B$, $C$, градусы. Поворот фланца:

$$
{}^{B}R_F(A, B, C) = R_z(A)\,R_y(B)\,R_x(C)
\tag{2.2.1}
$$

где $A$, $B$, $C$ — углы позы KUKA, градусы; буква $A$ без индексов — угол, а не матрица преобразования;
&emsp;&emsp;$R_z(A)$, $R_y(B)$, $R_x(C)$ — матрицы поворота на углы $A$, $B$, $C$ вокруг осей z, y, x.

По (2.2.1) ориентация A 180, B 0, C 180 направляет ось z фланца, то есть стилус, вертикально вниз.

## 5. Математическая модель калибровки и проверки

Модель связывает углы сочленений, зарегистрированные при касаниях, с искомыми параметрами: центром шарика в {F}, центром сферы в {B} и расстояниями касания. Она обобщает случай 2 моделей (раздел 2.4): расстояние касания оценивается отдельно для каждой из двух ориентаций щупа относительно силы тяжести. Факторы влияния $\mathrm{IF}_k$ и подфакторы $\mathrm{IF}_k^{j}$ — по разделу 3.2 анализа литературы.

### 5.1. Расчётный центр шарика и класс направления силы тяжести

Зададим величины, которые калибровка и проверка получают из каждого касания.

Углы сочленений $\bar{q}_i$ при касании $i$ (теория, раздел 2.1) берут из значения `AIPos` того пакета обмена RSI, в котором `$IN[8]` впервые равен TRUE (раздел 3.2). **Пакет обмена RSI** — XML-сообщение, которое контроллер отправляет компьютеру в каждом цикле 4 мс. Расчётный центр шарика при касании $i$:

$$
{}^{B}\bar{p}_r(\bar{q}_i,{}^{F}\bar{p}_r) = {}^{B}\bar{p}_F(\bar{q}_i) + {}^{B}R_F(\bar{q}_i)\,{}^{F}\bar{p}_r
\tag{5.1.1}
$$

где ${}^{B}\bar{p}_r(\bar{q}_i,{}^{F}\bar{p}_r)$ — расчётный центр шарика при касании $i$, мм;
&emsp;&emsp;${}^{F}\bar{p}_r$ — центр шарика в {F}, мм.

Позу фланца вычисляют номинальной прямой задачей кинематики (раздел 2.1) — той же, что при измерении деталей.

**Класс направления силы тяжести** (gravity direction class) — ориентации TCP, у которых орт силы тяжести в {P} одинаков. Оси {P} параллельны осям {F} (раздел 2.2), поэтому при ориентации TCP с углами $A$, $B$, $C$:

$$
{}^{P}\bar{e}_{gr}(A,B,C) = -\,{}^{B}R_F(A,B,C)^T\,{}^{B}\bar{e}_z
$$

где ${}^{P}\bar{e}_{gr}(A,B,C)$ — орт силы тяжести в {P}.

Ориентации TCP, отличающиеся только поворотом вокруг вертикальной оси {B}, принадлежат одному классу. Подставим в определение ${}^{P}\bar{e}_{gr}$ матрицу $R_z(\varphi)\,{}^{B}R_F(A,B,C)$ и учтём $R_z(\varphi)^T\,{}^{B}\bar{e}_z = {}^{B}\bar{e}_z$:

$$
-\left(R_z(\varphi)\,{}^{B}R_F(A,B,C)\right)^T{}^{B}\bar{e}_z = -\,{}^{B}R_F(A,B,C)^T R_z(\varphi)^T\,{}^{B}\bar{e}_z = -\,{}^{B}R_F(A,B,C)^T\,{}^{B}\bar{e}_z
$$

где $\varphi$ — угол поворота вокруг вертикальной оси {B}, °.

Пусть $o(i)$ — класс направления силы тяжести касания $i$ при ориентации TCP, заданной планом касания: $o(i) = \mathrm{v}$, если ${}^{P}\bar{e}_{gr}(A,B,C) = {}^{P}\bar{e}_z$ (стилус вертикально вниз); $o(i) = \mathrm{h}$, если ${}^{P}\bar{e}_{gr}(A,B,C) = {}^{P}\bar{e}_x$ (стилус горизонтален, ось x системы {P} направлена вниз; так при A 0, B 90, C 0).

### 5.2. Оценивание параметров калибровки

Запишем невязку калибровочного касания и задачу МНК, решение которой — результат калибровки.

Вектор искомых параметров:

$$
\bar{x} = \begin{bmatrix} {}^{F}\bar{p}_r^{\,T} & {}^{B}\bar{p}_s^{\,T} & \rho_{\mathrm{v}} & \rho_{\mathrm{h}} \end{bmatrix}^T
$$

где $\bar{x}$ — вектор-столбец размером $8 \times 1$;
&emsp;&emsp;$\rho_{\mathrm{v}}$, $\rho_{\mathrm{h}}$ — расстояния касания (теория, раздел 2.3) касаний классов v и h, мм.

Невязка калибровочного касания $i$ — (m.2.4.3) с расстоянием касания класса $o(i)$ вместо одного $\rho$. Подставим (5.1.1):

$$
\varepsilon_i(\bar{x}) = \left\| {}^{B}\bar{p}_r(\bar{q}_i,{}^{F}\bar{p}_r) - {}^{B}\bar{p}_s \right\| - \rho_{o(i)} = \left\| {}^{B}\bar{p}_F(\bar{q}_i) + {}^{B}R_F(\bar{q}_i)\,{}^{F}\bar{p}_r - {}^{B}\bar{p}_s \right\| - \rho_{o(i)}
\tag{5.2.1}
$$

где $\varepsilon_i(\bar{x})$ — невязка калибровочного касания $i$, мм;
&emsp;&emsp;$\rho_{o(i)}$ — $\rho_{\mathrm{v}}$ при $o(i) = \mathrm{v}$ и $\rho_{\mathrm{h}}$ при $o(i) = \mathrm{h}$, мм.

Результат калибровки:

$$
\boxed{\hat{\bar{x}} = \arg\min_{\bar{x} \in \mathbb{R}^8} \sum_{i \in I_{\mathrm{cal}}} \varepsilon_i(\bar{x})^2}
\tag{5.2.2}
$$

где $\hat{\bar{x}}$ — вектор параметров, найденный МНК; его элементы — ${}^{F}\hat{\bar{p}}_r$, ${}^{B}\hat{\bar{p}}_s$, $\hat{\rho}_{\mathrm{v}}$, $\hat{\rho}_{\mathrm{h}}$;
&emsp;&emsp;$I_{\mathrm{cal}}$ — множество номеров калибровочных касаний; в плане раздела 6.1 их 114.

Задачу (5.2.2) решают методом Гаусса — Ньютона (модели, раздел 2.2.4). Начальное приближение: ${}^{F}\bar{p}_r$ — TOOL_DATA[5] (раздел 1), ${}^{B}\bar{p}_s$ — центр аппроксимации ручных касаний (раздел 4.2), $\rho_{\mathrm{v}} = \rho_{\mathrm{h}} = L$.

Расстояний касания два, по одному на класс направления силы тяжести, по двум основаниям:

1. Ход до срабатывания зависит от ориентации щупа относительно силы тяжести: у щупов из L5 и L6 вес держателя и стилуса меняет силу срабатывания по направлениям в зависимости от ориентации щупа (разделы 3.3.4, 3.3.5 анализа литературы). У касаний одного класса орт силы тяжести в {P} одинаков по определению класса (раздел 5.1).
2. Детали измеряют в ориентациях обоих классов: стилус вертикально вниз и горизонтально вдоль оси x системы {B} (решение пользователя, 2026-11-11); для каждого класса нужен свой эффективный радиус шарика (5.3.3).

Сравнение с одним и с тремя расстояниями касания — раздел 6.2.

Каждое калибровочное направление выполняется дважды в одной и той же группе ориентации (раздел 6.1). Пусть $\Pi$ — множество пар номеров $(i, i')$ двух калибровочных касаний с одинаковыми группой ориентации, наклоном $\tau$ и поворотом $\psi$. Позы касаний пары совпадают в пределах разброса обнаружения, поэтому у них одинаковы систематическая часть невязки (модели, раздел 4.1) и строка матрицы Якоби; разность невязок пары при $\hat{\bar{x}}$ содержит разность случайных частей. Дисперсия разности двух независимых случайных частей с одинаковым СКО $\sigma$ равна $2\sigma^2$, отсюда оценка СКО случайной погрешности одного касания:

$$
s_{\mathrm{rep}} = \sqrt{\frac{1}{2\,\lvert\Pi\rvert}\sum_{(i,i') \in \Pi} \left(\varepsilon_i(\hat{\bar{x}}) - \varepsilon_{i'}(\hat{\bar{x}})\right)^2}
\tag{5.2.3}
$$

где $s_{\mathrm{rep}}$ — оценка СКО случайной погрешности касания по повторам, мм;
&emsp;&emsp;$\lvert\Pi\rvert$ — число пар; в плане раздела 6.1 оно равно 57.

В отличие от оценки по сумме квадратов невязок (m.2.3.11), $s_{\mathrm{rep}}$ не содержит систематических частей невязок, одинаковых у касаний пары. Изменение уровня фактора между двумя касаниями пары, например тепловой дрейф, входит в $s_{\mathrm{rep}}$.

### 5.3. Невязка проверочного касания и КТК

Запишем невязку проверочного касания для двух расстояний касания, оценку КТК по проверочным касаниям и эффективный радиус шарика для измерения деталей.

Центр сферы по проверочным касаниям при неизменных результатах калибровки:

$$
{}^{B}\hat{\bar{p}}_{\mathrm{ver}} = \arg\min_{{}^{B}\bar{p} \in \mathbb{R}^3} \sum_{i \in I_{\mathrm{ver}}} \left( \left\| {}^{B}\bar{p}_r(\bar{q}_i,{}^{F}\hat{\bar{p}}_r) - {}^{B}\bar{p} \right\| - \hat{\rho}_{o(i)} \right)^2
\tag{5.3.1}
$$

где ${}^{B}\hat{\bar{p}}_{\mathrm{ver}}$ — центр эталонной сферы, найденный МНК по проверочным касаниям, мм;
&emsp;&emsp;${}^{B}\bar{p}$ — переменная минимизации: положение центра сферы в {B}, мм;
&emsp;&emsp;$I_{\mathrm{ver}}$ — множество номеров проверочных касаний; в плане раздела 7.1 их 44.

Невязка проверочного касания — (4.3.1) теории с расстоянием касания класса касания вместо одного $\hat{\rho}$:

$$
\boxed{\varepsilon_{\mathrm{ver},i} = \left\| {}^{B}\bar{p}_r(\bar{q}_i,{}^{F}\hat{\bar{p}}_r) - {}^{B}\hat{\bar{p}}_{\mathrm{ver}} \right\| - \hat{\rho}_{o(i)}, \qquad i \in I_{\mathrm{ver}}}
\tag{5.3.2}
$$

КТК $\chi_{95}$ — (4.3.2) теории с невязкой (5.3.2). Его оценка по 44 проверочным касаниям — значение с номером $\lceil 0{,}95 \cdot 44 \rceil = \lceil 41{,}8 \rceil = 42$ среди значений $\lvert\varepsilon_{\mathrm{ver},i}\rvert$, упорядоченных по возрастанию (теория, раздел 4.3).

При измерении деталей точку поверхности вычисляют по (m.2.4.5) с эффективным радиусом шарика класса направления силы тяжести касания детали:

$$
r_{eff,o} = \hat{\rho}_o - r_s, \qquad o \in \{\mathrm{v}, \mathrm{h}\}
\tag{5.3.3}
$$

где $r_{eff,o}$ — эффективный радиус шарика класса $o$, мм;
&emsp;&emsp;$r_s$ — номинальный радиус эталонной сферы, 12,5 мм (раздел 2.3).

## 6. Процедура калибровки

Опишем план калибровочных касаний, однозначность оценки (5.2.2) при этом плане, шаги процедуры и действие каждого шага на факторы влияния.

### 6.1. План калибровочных касаний

Зададим уровни подфакторов $\mathrm{IF}_{16}$ (состав, последовательность и условия выполнения касаний): группы ориентации, направления подхода, проходы и их порядок.

**Группа ориентации** (orientation group) — набор касаний с одной ориентацией TCP; ориентация меняется только между группами. $R_g$ — матрица поворота группы $g$ по (2.2.1) с углами A, B, C из таблицы:

| <nobr>Группа</nobr> | <nobr>A,</nobr> <nobr>B,</nobr> <nobr>C,</nobr> ° | <nobr>Ось</nobr> <nobr>стилуса</nobr> <nobr>в</nobr> {B} | <nobr>Класс</nobr> | <nobr>Назначение</nobr> |
| --- | --- | --- | --- | --- |
| G1 | (180; 0; 180) | $-{}^{B}\bar{e}_z$ | v | ориентация измерения деталей со стилусом вниз |
| G2 | (0; 90; 0) | ${}^{B}\bar{e}_x$ | h | ориентация измерения деталей со стилусом вдоль оси x; ориентация в HOME |
| G3 | (0; 0; 180) | $-{}^{B}\bar{e}_z$ | v | G1, повёрнутая на 180° вокруг стилуса: без неё центр шарика неидентифицируем (раздел 6.2) |

Группы G1 и G2 выбраны по ориентациям, в которых измеряют детали (раздел 5.2, основание 2): $\hat{\rho}_{\mathrm{v}}$, $\hat{\rho}_{\mathrm{h}}$ и центр шарика оценивают по касаниям в тех же ориентациях, в которых их применяют при измерении деталей. Группа G3 добавлена только для идентифицируемости центра шарика (раздел 6.2); как и G1, она относится к классу v и нового расстояния касания не вводит.

Направление подхода касания задают наклоном $\tau$ и поворотом $\psi$ (теория, раздел 2.2). Ориентация {P} в группе $g$ — $R_g$, так как оси {P} параллельны осям {F}. По (2.2.2) теории орт нормали противоположен орту подхода, а орт подхода в {B} — орт (2.2.4) теории, повёрнутый матрицей $R_g$:

$$
{}^{B}\bar{e}_n(g,\tau,\psi) = -\,R_g\,{}^{P}\bar{e}_a(\tau,\psi)
\tag{6.1.1}
$$

где ${}^{B}\bar{e}_n(g,\tau,\psi)$ — орт внешней нормали сферы в точке касания группы $g$ с наклоном $\tau$ и поворотом $\psi$.

Точки касания и старта рассчитывают по центру аппроксимации ручных касаний ${}^{B}\bar{p}_{s.0}$ (раздел 4.2): точка номинального касания ${}^{B}\bar{p}_{s.0} + L\,{}^{B}\bar{e}_n(g,\tau,\psi)$, точка старта ${}^{B}\bar{p}_{s.0} + L_{st}\,{}^{B}\bar{e}_n(g,\tau,\psi)$, $L_{st} = L + 3 = 17$ мм. Предподхода нет: точка старта совпадает с точкой ожидания (теория, раздел 2.3). **Оболочка старта** (start shell) — сфера радиуса $L_{st}$ с центром ${}^{B}\bar{p}_{s.0}$.

Калибровочные направления одинаковы во всех трёх группах. **Кольцо наклона** (tilt ring) — направления с одним $\tau$:

| <nobr>Кольцо</nobr> $\tau$, ° | $\psi$, ° | <nobr>Число</nobr> <nobr>направлений</nobr> |
| --- | --- | --- |
| 0 | — | 1 |
| 30 | 0, 60, 120, 180, 240, 300 | 6 |
| 45, 60, 75, 90 | 60, 180, 300 | по 3 |

Всего 19 направлений. Наклон не больше 90°: при $\tau = 90°$ хвостовик стилуса радиусом 1,0 мм проходит в $14 - 12{,}5 - 1{,}0 = 0{,}5$ мм от сферы, при большем наклоне пересекает её (радиус хвостовика — по CAD-модели щупа WP-500); касание при $\tau = 90°$ нужно для стенок отверстий. В G2 по (6.1.1) и (2.2.4) теории координата z нормали равна $-\sin\tau\cos\psi$, и проверку зазора до стойки не меньше 3 мм проходят касания с $\sin\tau\cos\psi \le 0{,}5$ — точка касания не ниже широты −30°. Набор составлен из направлений, выполнимых в G2: кольцо 30° целиком, кольца 45°–90° — только повороты 60°, 180°, 300°.

Повороты внутри кольца взяты с равным шагом, чтобы периодическая по $\psi$ составляющая хода до срабатывания не смещала найденные параметры. Пусть составляющая хода до срабатывания в кольце с наклоном $\tau$ равна $a_\nu(\tau)\cos(\nu\psi + \varphi_\nu)$, где $\nu$ — порядок составляющей, целое число (у кинематического щупа Renishaw в L4 зависимость от азимута треугольная, $\nu = 3$: раздел 3.3.3 анализа литературы); $a_\nu(\tau)$ — амплитуда, мм; $\varphi_\nu$ — фаза, рад. В линейном приближении (m.4.6.2) составляющая смещает найденные параметры, только если она не ортогональна столбцам матрицы Якоби. В кольце эти столбцы — функции $\psi$ вида $1$, $\cos\psi$, $\sin\psi$: столбец расстояния касания постоянен, столбцы центров шарика и сферы — элементы ${}^{P}\bar{e}_a(\tau,\psi)$ по (2.2.4) теории и ${}^{B}\bar{e}_n(g,\tau,\psi)$ (6.1.1). Пусть повороты кольца $\psi_h = \psi_0 + 360°\,h/N_\psi$, $h = 0, \ldots, N_\psi - 1$. По формулам произведения синуса и косинуса:

$$
\begin{gathered}
\sum_{h=0}^{N_\psi-1} \cos(\nu\psi_h + \varphi_\nu)\cos\psi_h = \frac{1}{2}\sum_{h=0}^{N_\psi-1}\left[\cos\left((\nu - 1)\psi_h + \varphi_\nu\right) + \cos\left((\nu + 1)\psi_h + \varphi_\nu\right)\right],\\
\sum_{h=0}^{N_\psi-1} \cos(\nu\psi_h + \varphi_\nu)\sin\psi_h = \frac{1}{2}\sum_{h=0}^{N_\psi-1}\left[\sin\left((\nu + 1)\psi_h + \varphi_\nu\right) - \sin\left((\nu - 1)\psi_h + \varphi_\nu\right)\right]
\end{gathered}
$$

где $N_\psi$ — число поворотов в кольце;
&emsp;&emsp;$\psi_0$ — поворот с номером $h = 0$, °;
&emsp;&emsp;$h$ — номер поворота.

При целом $\mu$, не кратном $N_\psi$, суммы $\sum_h \cos(\mu\psi_h + \varphi_\nu)$ и $\sum_h \sin(\mu\psi_h + \varphi_\nu)$ равны нулю: это вещественная и мнимая части суммы геометрической прогрессии $\sum_h \exp\left(\mathrm{i}\,(\mu\psi_h + \varphi_\nu)\right)$, где $\mathrm{i}$ — мнимая единица, а углы выражены в радианах; знаменатель прогрессии $\exp(2\pi\mathrm{i}\,\mu/N_\psi)$ отличен от 1, а его степень $N_\psi$ равна 1. Сумма со столбцом $1$ — та же сумма при $\mu = \nu$. Отсюда:

$$
\boxed{\text{составляющая порядка } \nu \text{ не смещает параметры, если ни } \nu, \text{ ни } \nu - 1, \text{ ни } \nu + 1 \text{ не кратны } N_\psi}
\tag{6.1.2}
$$

При $N_\psi = 6$ (кольцо 30°) условие (6.1.2) для $\nu = 3$ выполнено. При $N_\psi = 3$ (кольца 45°–90°) для $\nu = 3$ суммы с $\cos\psi$ и $\sin\psi$ равны нулю ($\nu \pm 1 = 2, 4$), но $\nu$ кратно 3: сумма составляющей по кольцу $3\,a_3(\tau)\cos(3\psi_0 + \varphi_3)$ не равна нулю. Её среднее по кольцу входит в столбец расстояния касания и в столбец координаты z центра шарика (элемент $\cos\tau$ орта (2.2.4) теории); если $a_3(\tau)$ различна у колец, она смещает $\hat{\rho}_o$ и координату z центра шарика.

**Проход** (pass) — однократное выполнение списка направлений группы. Порядок проходов:

| <nobr>№</nobr> | <nobr>Назначение</nobr> | <nobr>Группа</nobr> | <nobr>Порядок</nobr> <nobr>направлений</nobr> |
| --- | --- | --- | --- |
| 1 | калибровка | G1 | прямой |
| 2 | калибровка | G2 | прямой |
| 3 | калибровка | G3 | прямой |
| 4 | калибровка | G3 | обратный |
| 5 | калибровка | G2 | обратный |
| 6 | калибровка | G1 | обратный |
| 7 | проверка | G1 | прямой (раздел 7.1) |
| 8 | проверка | G2 | прямой (раздел 7.1) |

Калибровочных касаний $3 \cdot 19 \cdot 2 = 114$. **Прямой порядок** — порядок наименьшего суммарного времени перемещений по оболочке старта, начиная с $\tau = 0$, при зазоре до стойки не меньше 3 мм в G2 (точный перебор при планировании); на точность он не влияет.

### 6.2. Однозначность оценки при плане калибровки

Докажем, что при плане раздела 6.1 в линейном приближении параметры $\bar{x}$ определяются однозначно, найдём, какая группа ориентации для этого необходима, и сравним два расстояния касания с одним и с тремя.

Параметры неидентифицируемы, если существует $\Delta\bar{x} \ne \bar{0}$, при котором изменения всех невязок (5.2.1) в линейном приближении равны нулю (m.2.2.17). Изменение невязки касания $i$ по производным (m.2.2.9) и $\partial\varepsilon_i(\bar{x})/\partial\rho_{o(i)} = -1$:

$$
\Delta\varepsilon_i = {}^{B}\bar{e}_{sr}(\bar{q}_i,\bar{x})^T\left({}^{B}R_F(\bar{q}_i)\,\Delta{}^{F}\bar{p}_r - \Delta{}^{B}\bar{p}_s\right) - \Delta\rho_{o(i)}
$$

где $\Delta\varepsilon_i$ — изменение невязки касания $i$, мм;
&emsp;&emsp;$\Delta{}^{F}\bar{p}_r$, $\Delta{}^{B}\bar{p}_s$, $\Delta\rho_{o(i)}$ — изменения элементов $\bar{x}$, мм.

В группе $g$ по плану ${}^{B}R_F(\bar{q}_i) = R_g$. По допущению 2 из (m.2.4.1) ${}^{B}\bar{e}_{sr}(\bar{q}_i,\bar{x}) = {}^{B}\bar{e}_n(g,\tau_i,\psi_i)$. Подставим оба равенства и (6.1.1); обозначим $\bar{d}_g = \begin{bmatrix} d_{g,x} & d_{g,y} & d_{g,z} \end{bmatrix}^T = -R_g^T\left(R_g\,\Delta{}^{F}\bar{p}_r - \Delta{}^{B}\bar{p}_s\right)$, мм, и $o(g)$ — класс группы $g$:

$$
\begin{gathered}
\Delta\varepsilon_i = -\left(R_g\,{}^{P}\bar{e}_a(\tau_i,\psi_i)\right)^T\left(R_g\,\Delta{}^{F}\bar{p}_r - \Delta{}^{B}\bar{p}_s\right) - \Delta\rho_{o(g)} =\\
= -\,{}^{P}\bar{e}_a(\tau_i,\psi_i)^T R_g^T\left(R_g\,\Delta{}^{F}\bar{p}_r - \Delta{}^{B}\bar{p}_s\right) - \Delta\rho_{o(g)} = {}^{P}\bar{e}_a(\tau_i,\psi_i)^T\,\bar{d}_g - \Delta\rho_{o(g)}
\end{gathered}
$$

Подставим в $\Delta\varepsilon_i = 0$ орт (2.2.4) теории для направлений плана. При $\tau = 0$: $d_{g,z} = \Delta\rho_{o(g)}$. При $\tau = 90°$ и $\psi = 60°, 180°, 300°$: $-d_{g,x}\cos\psi + d_{g,y}\sin\psi = \Delta\rho_{o(g)}$. Сложим три равенства: суммы $\cos\psi$ и $\sin\psi$ по трём поворотам с шагом 120° равны нулю, поэтому $3\,\Delta\rho_{o(g)} = 0$. Тогда при $\psi = 180°$ получаем $d_{g,x} = 0$, при $\psi = 60°$ — $d_{g,y} = 0$, а из первого равенства $d_{g,z} = 0$. Следовательно, в каждой группе:

$$
\Delta\rho_{o(g)} = 0, \qquad R_g\,\Delta{}^{F}\bar{p}_r = \Delta{}^{B}\bar{p}_s, \qquad g = 1, 2, 3
$$

Из второго равенства для групп 1 и 2 и для групп 1 и 3 следует $R_1^T R_2\,\Delta{}^{F}\bar{p}_r = \Delta{}^{F}\bar{p}_r$ и $R_1^T R_3\,\Delta{}^{F}\bar{p}_r = \Delta{}^{F}\bar{p}_r$. По (2.2.1) и таблице групп $R_1 = R_z(180°)\,R_x(180°) = \operatorname{diag}(-1, 1, -1)$, $R_2 = R_y(90°)$, $R_3 = R_x(180°) = \operatorname{diag}(1, -1, -1)$. Перемножим:

$$
R_1^T R_2 = \begin{bmatrix} -1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & -1 \end{bmatrix} \begin{bmatrix} 0 & 0 & 1 \\ 0 & 1 & 0 \\ -1 & 0 & 0 \end{bmatrix} = \begin{bmatrix} 0 & 0 & -1 \\ 0 & 1 & 0 \\ 1 & 0 & 0 \end{bmatrix} = R_y(-90°),
\qquad
R_1^T R_3 = \begin{bmatrix} -1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & -1 \end{bmatrix} \begin{bmatrix} 1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & -1 \end{bmatrix} = \begin{bmatrix} -1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1 \end{bmatrix} = R_z(180°)
$$

$R_y(-90°)$ оставляет неподвижными только векторы вдоль ${}^{F}\bar{e}_y$, $R_z(180°)$ — только векторы вдоль ${}^{F}\bar{e}_z$. Общий неподвижный вектор — только нулевой, поэтому $\Delta{}^{F}\bar{p}_r = \bar{0}$ и $\Delta{}^{B}\bar{p}_s = R_1\,\Delta{}^{F}\bar{p}_r = \bar{0}$:

$$
\boxed{\Delta\varepsilon_i = 0 \;\; \forall i \in I_{\mathrm{cal}} \;\Longrightarrow\; \Delta\bar{x} = \bar{0}}
$$

Без группы G3 остаётся решение $\Delta{}^{F}\bar{p}_r = \theta\,{}^{F}\bar{e}_y$, $\Delta{}^{B}\bar{p}_s = \theta\,R_1\,{}^{F}\bar{e}_y$, $\theta \in \mathbb{R}$: составляющая центра шарика вдоль оси y системы {F} — оси поворота от G1 к G2 — неидентифицируема. Доказательство использует допущение 2 из (m.2.4.1) и не исключает вырождения нелинейной задачи; для полученных касаний ранг $J(\hat{\bar{x}})$ проверяют вычислением (модели, раздел 2.2.5).

### 6.3. Шаги процедуры

Перечислим шаги в порядке выполнения.

1. **К1. Подготовка.** Сфера и стойка остаются на месте ручных касаний (раздел 4.1); шарик и сферу очищают (L28, раздел 3.6.2 анализа литературы). Исходные данные: центр ${}^{B}\bar{p}_{s.0}$ — по разделу 4.2, радиусы шарика и сферы — по разделу 2.3, размеры стойки — по разделу 2.1.
2. **К2. Расчёт движения.** По плану раздела 6.1 рассчитывают движение от HOME до HOME. Для каждой рассчитанной точки движения решают обратную задачу кинематики и проверяют, что углы сочленений не выходят за пределы, скорости сочленений не больше номинальных, а декартово ускорение TCP не больше 10000 мм/с² (`$ACC_MA.CP` контроллера). В каждой рассчитанной точке шарик должен отстоять от стойки не меньше чем на 3 мм, вне поиска и отвода — от сферы не меньше чем на 3 мм. Движение, в котором нарушено хотя бы одно из этих условий, не выполняют.
3. **К3. Задание для контроллера.** Движение записывают для контроллера как последовательность шагов PTP, LIN, CIRC, поиска и возврата в HOME. Для каждого поиска рассчитывают поток поправок RSI: 1250 приращений по 0,004 мм вдоль $-{}^{B}\bar{e}_n(g,\tau,\psi)$, по одному на цикл 4 мс, — всего 5 мм при скорости поиска 1 мм/с, затем 50 нулевых поправок. Для каждого касания записывают группу, проход, $\tau$, $\psi$, нормаль и номинальные позы.
4. **К4. Выполнение проходов 1–6.** Робот выполняет PTP к входной позе прохода — 60 мм наружу по нормали первого касания и 80 мм выше — и LIN к первой точке старта. Затем для каждого касания: перемещение CIRC по оболочке старта (кроме первого касания прохода), поиск, отвод LIN в точку старта. Перемещения и отвод — со скоростью 10 мм/с и ускорением 20 мм/с², ориентация TCP при них постоянна. Поиск — одно включение RSI: TCP движется с постоянной скоростью 1 мм/с от точки старта вдоль $-{}^{B}\bar{e}_n(g,\tau,\psi)$, объект STOP контекста RSI (раздел 3.1) останавливает движение по переднему фронту `$IN[8]`. Между группами: LIN к точке в 42 мм от центра сферы по нормали последнего касания, PTP к входной позе следующей группы, LIN к её первой точке старта.
5. **К5. Регистрация.** Записывают каждый пакет обмена RSI. Для каждого касания берут $\bar{q}_i$ по разделу 5.1, а также углы предыдущего пакета и число циклов от начала поиска.
6. **К6. Оценивание.** Решение (5.2.2) по касаниям проходов 1–6; вычисление ранга $J(\hat{\bar{x}})$ (раздел 6.2); оценка $s_{\mathrm{rep}}$ (5.2.3).
7. **К7. Проверка невязок и выбор модели.** Средние невязки касаний каждой группы по каждому кольцу наклона и по каждому повороту сравнивают с границей $3\,s_{\mathrm{rep}}/\sqrt{m_k}$ проверки 3 моделей (раздел 2.5), где $m_k$ — число касаний в сравниваемом наборе. Слагаемое модели, зависящее от $\tau$ или $\psi$, добавляют, только если средняя невязка набора выходит за эту границу. Из моделей-кандидатов оставляют модель с наименьшим $\chi_{95}$ по проверочным касаниям (раздел 7.2) — правило шага 7 теории (раздел 1). Базовая модель — (5.2.1).
